## Perfect: Server-Side Swift

Focused Swift packages for building servers and talking to the services behind them. Every
package is written for Swift 6 and strict concurrency, runs on macOS and Linux, keeps its
dependencies to a minimum, and is released and tested on its own.

**Start here:** [PerfectTemplate](https://github.com/PerfectlySoft/PerfectTemplate), a small web
app built from the packages below, and
[Perfect-NIO](https://github.com/PerfectlySoft/Perfect-NIO), the HTTP(S) server.

| **Server and web** | [Perfect-NIO](https://github.com/PerfectlySoft/Perfect-NIO) · [Perfect-Session](https://github.com/PerfectlySoft/Perfect-Session) · [Perfect-Authentication](https://github.com/PerfectlySoft/Perfect-Authentication) · [Perfect-SMTP](https://github.com/PerfectlySoft/Perfect-SMTP) · [Perfect-Notifications](https://github.com/PerfectlySoft/Perfect-Notifications) |

The [Perfect](https://github.com/PerfectlySoft/Perfect) repository describes each package and
shows what replaced the original PerfectLib-era packages. Those older repositories are archived:
read-only, with their tags still resolving. Every package that existed before Swift 6 keeps its old
code on a `legacy` branch.
